# Security / Seguridad

Report vulnerabilities privately through this repository's GitHub Security Advisories when available. Avoid publishing exploitation details or secrets in an issue. Include the affected version, a fictional reproduction, impact and proposed mitigation. Public-key certificates are not private keys.

Comunica vulnerabilidades de forma privada mediante GitHub Security Advisories cuando esté disponible en el repositorio. No publiques secretos ni instrucciones de explotación en issues. Incluye versión, reproducción ficticia, impacto y posible mitigación.

See [security architecture](docs/security.en.md) / [seguridad](docs/security.md). Cloud acceptance, internal-hop TLS requirements, recovery exercises, IAM review and organizational policies remain installation responsibilities. Local tests are not a security certification.
